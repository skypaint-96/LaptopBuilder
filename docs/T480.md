# ThinkPad T480 notes

The default configuration targets a Lenovo ThinkPad T480 with an Intel CPU and Intel integrated graphics.

## Firmware first

Update BIOS/UEFI and Thunderbolt firmware before wiping the existing operating system. The T480 generation received important Thunderbolt controller firmware updates; an outdated controller can lead to unreliable USB-C/Thunderbolt operation and, in severe cases, loss of port functionality.

Use Lenovo's supported update path from the existing operating system when possible. After Arch is installed, the T480 role installs and enables `fwupd` refresh support. Check for supported updates with:

```bash
sudo fwupdmgr refresh --force
fwupdmgr get-devices
fwupdmgr get-updates
sudo fwupdmgr update
```

Keep the laptop on AC power and follow firmware-specific reboot instructions.

## Firmware configuration

Press **F1** during startup. Menu labels vary by firmware revision, but the repository expects:

- UEFI-only boot;
- legacy/CSM compatibility disabled;
- the security chip/TPM 2.0 enabled;
- Secure Boot disabled while using the official Arch ISO;
- Secure Boot Setup Mode available for first owner-key enrollment;
- Secure Boot enabled only after `archctl secure-boot` has enrolled and signed the final boot chain.

A firmware supervisor password is recommended once the settings are proven. Store it outside the laptop.

## Graphics variants

The normal profile is:

```bash
CPU_VENDOR="intel"
GPU_VENDOR="intel"
ENABLE_T480=true
```

Some T480 variants may have discrete NVIDIA graphics. This repository does not configure NVIDIA proprietary drivers, PRIME offload, discrete-GPU power control, or the additional Secure Boot module-signing path. Use the Intel-only mode in firmware only when the specific model and workflow support it; otherwise create and test a dedicated hybrid-graphics role before installation.

## Power and thermal policy

The T480 role installs:

- `tlp` and `tlp-rdw` for laptop power policy;
- `thermald` for Intel thermal management;
- `fwupd` for supported firmware updates;
- `bolt` for Thunderbolt device authorisation support;
- `smartmontools` for storage health monitoring;
- `ethtool` for network diagnostics.

The supplied TLP profile is conservative. It changes energy-performance policy and Wi-Fi power saving while leaving most TLP defaults intact.

Battery charge thresholds are disabled by default because they are personal policy. To limit long-term time at full charge:

```bash
T480_BATTERY_THRESHOLDS=true
T480_START_CHARGE=40
T480_STOP_CHARGE=80
```

After provisioning, inspect:

```bash
sudo tlp-stat -s
sudo tlp-stat -b
systemctl status tlp thermald
```

The T480 can have one internal and one removable battery. The template applies the same thresholds to BAT0 and BAT1 when enabled.

## Docking and Thunderbolt

After firmware is current, inspect the controller and attached devices:

```bash
boltctl list
fwupdmgr get-devices
```

Test charging, external displays, Ethernet, USB, suspend/resume, and hot-plug behaviour before depending on a dock for work. Microsoft UEFI certificates are retained by default partly to reduce compatibility problems with signed expansion-device firmware and option ROMs.

## Suspend and hibernation

Normal suspend is provided by the desktop and kernel. Hibernation is not configured. The repository uses zram rather than an on-disk swapfile, avoiding a fragile encrypted Btrfs resume configuration.

Test suspend and resume on battery and AC after firmware and kernel updates. The LTS kernel remains available when a regression affects the current kernel.
